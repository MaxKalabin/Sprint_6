# Sprint_6 Тестирование сайта "Самокат"
Автотесты для главной страницы сервиса заказа самокатов: https://qa-scooter.praktikum-services.ru/

# Функционал тестирования
1. Поддержка двух точек входа
   1. Верхняя кнопка "Заказать"
   2. Нижняя кнопка "Заказать"
2. Оформление заказа самоката
   1. Заполнение формы: имя, фамилия, адрес, метро, телефон
   2. Выбор даты, периода аренды, цвета и комментария
   3. Подтверждение заказа
   4. Проверка модального окна с номером заказа
3. Переход по логотипам
   1. Нажатие на логотип «Самоката» — должен вернуть на главную
   2. Нажатие на логотип Яндекса — открывает Дзен
4. Проверка вопросов в разделе "Вопросы о важном"
   1. Клик по каждому из 8 вопросов в футтере
   2. Проверка соответствия текста ответа

# Основа для написания автотестов — фреймворк pytest.

# Установить зависимости
pip3 install -r requirements.txt
# Команда для запуска
pytest tests/ -v
# Команда для генерации отчета в Allure:
pytest tests/ --alluredir=./allure-results
# Команда для просмотра результата в Allure:
allure serve ./allure-results
